# 评估结果 ↔ 医学标准 对照表

> **用途：** 比赛讲解用。列出**每一种评估结果**对应的**判定标准**，以及该标准**出自哪一份医学来源**。  
> 本文档把「代码里到底怎么判的」和「这个判法出自哪条医学标准」逐条对齐，并**诚实标出哪些阈值有来源、哪些是我方自行设定**。

**版本：** v3.12-binary-options ｜ **日期：** 2026-10-13  
**配套文件：** `docs/中文说明/data-sources-and-grading-zh.md`（数据源登记 + 分级标准总览）、`docs/中文说明/question-bank-and-selection-logic-zh.md`（逐题权重，自动生成）

## 0 · 30 秒讲解路径

1. 应用产出 **5 类结果**，其中**就医层级**是主结果 —— 回答「现在该去哪」。
2. 就医层级由 **13 条确定性规则**决定，**没有任何 AI 参与**：同一份答案永远得到同一个结果。
3. 规则来自四套**可公开下载、逐条可查**的标准：**SIRS 1992**（全身炎症反应）、**IWGDF/IDSA 2023**（糖尿病足感染分级）、**IWGDF 2023**（足溃疡风险分层）、**NICE NG19**（英国糖尿病足防治指南）。
4. 严重度分数与就医层级**故意解耦**：分数回答「有多严重」，层级回答「该去哪」。LLM 只能**解释**层级，**不能修改**。
5. 信息不足或自相矛盾时，我们**弃权**（ABSTAIN）而不是猜。

> **一句话：** 这不是一个「AI 猜病」的应用，而是把**已发表的临床分级标准写成确定性规则**的筛查与就医导航工具。

## 3 · 风险等级（第二结果）

**判定方式：** `ratio = 加权总分 / 满分`，按下列顺序取第一个命中项。

| 顺序 | 条件                               | 结果           | 依据                                   |
| -- | -------------------------------- | ------------ | ------------------------------------ |
| 1  | 紧急标志含 `chronicWound`             | **urgent**   | IWGDF-W02：伤口 >2 周不愈合 = 慢性不愈合伤口，需紧急转诊 |
| 2  | 有**任何**紧急标志，**或** `ratio ≥ 0.85` | **high**     | 标志来自 §4；**0.85 是我方分档**               |
| 3  | `ratio ≥ 0.60`                   | **moderate** | **0.60 是我方分档**                       |
| 4  | 其余                               | **low**      | 兜底                                   |

- 每个选项的权重数值**是我方标定**的（见自动生成的题库文档），**不是**指南给的分数。
- 满分**随当次抽到的题浮动**（每次只问 7 题必答 + 4 题个性化），所以分数只用于**分档**，不对外当作「严重度百分比」宣称。
- **注：** `historyUlcer`（既往溃疡）与 `amputationHistory`（既往截肢）都是**已愈合的既往事件**，但都会把风险等级抬到 `high`（IWGDF 3 级）。这是**有意的保守设计**：既往溃疡的复发风险最高，不应显示为「低风险」。

## 5 · IWGDF 分级（Category 0–3）

**判定方式：** `clinicalRules.ts` → `mapToIWGDFCategory()`。**用途：** 决定复评频率；现已在**建议页**展示。  
**v3.10 起改为 IWGDF 忠实组合规则**（三项占其二 → 2 级；恰好一项 → 1 级）。

| 顺序 | 条件                                                        | 结果    | IWGDF 2023 定义                                  | 指南筛查区间  | 本项目取值         |
| -- | --------------------------------------------------------- | ----- | ---------------------------------------------- | ------- | ------------- |
| 1  | 标志含 `historyUlcer` / `amputationHistory` / `chronicWound` | **3** | （LOPS 或 PAD）**+** 既往溃疡 / 截肢 / 肾脏替代 / Charcot 足 | 1–3 个月  | **1 个月**（保守端） |
| 2  | LOPS / PAD / 足畸形 三项中 **≥2 项**                             | **2** | LOPS+PAD，或 LOPS+足畸形，或 PAD+足畸形                  | 3–6 个月  | **3 个月**（保守端） |
| 3  | LOPS ≥30% **或** 循环（PAD）≥30%，且**恰好一项**                     | **1** | LOPS **或** PAD                                 | 6–12 个月 | **6 个月**（保守端） |
| 4  | 其余                                                        | **0** | 无 LOPS、无 PAD、无畸形                               | 12 个月   | **12 个月**     |

> **口径统一（v3.10 修复）：** `IWGDF_CATEGORIES[].screeningFrequency` 的**文字区间**与 `IWGDF_SCREENING_INTERVAL_MONTHS` 的**数值**现已完全一致（12 / 6–12 / 3–6 / 1–3 个月，取保守端 12/6/3/1），并新增单测断言「数值必须落在文字区间内」，防止再次漂移。  
> **单足畸形** 单独出现仍为 **0 级** —— IWGDF 未把「单独足畸形」列为风险类别。  
> **代理说明：** 我们用**问卷类别得分**（神经病变 ≥30% / 循环 ≥30% / 皮肤 ≥40%）近似 LOPS 与 PAD 的**临床检查结果**（10 g 单丝、ABI），属工程近似，见 §7。

## 6 · 弃权（ABSTAIN）的判定依据

| 规则             | 触发条件（3 种矛盾组合 + 1 种信息不足）                                                                      | 依据                                                      |
| -------------- | -------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| **AB-01** 自相矛盾 | ① `s1`「皮肤颜色无变化」但勾选了「受压发红」<br />② `n1`「感觉正常」但 `n3`「感觉不到轻触」<br />③ `w1`「从未有过伤口」但现在勾选「裂口 / 新水泡」 | 安全设计：矛盾输入不猜                                             |
| **AB-02** 信息不足 | 5 项红旗中 **≥2 项未作答**，且无明确局部伤口                                                                  | **我方安全保守标定**：信息不足时宁可转诊；SIRS「≥2 项」作为**支持性**（非推导性）证据，见 §7 |


**二态逻辑（v3.12 更新）：** 红旗问题现仅有「是 / 否」两个选项（移除了「不确定」选项），使评估结果更精确。`undefined` 状态仅表示「尚未作答」，在正常 UI 流程中不会出现（每题必须选择才能进入下一题）。该状态作为编程接口的安全网保留：程序化调用传入不完整答案时仍会触发 ABSTAIN。

> **为什么阈值是 2 而不是 4？** 阈值越低越保守 —— 每一项「未作答」都是一个**未被排除的急症可能**。选 2 是我们主动的安全取向，不是指南硬性规定；该值已参数化（`TRIAGE_METADATA.abstainThreshold`），可用合成数据再标定。

## 7 · 诚实披露：哪些有来源、哪些是我方设定

> 这一节建议**主动讲出来**。评委最反感的是把自定阈值说成指南标准；主动区分反而加分。

### ✅ 有明确指南来源

| 标准                                                                              | 来源                                                   |
| ------------------------------------------------------------------------------- | ---------------------------------------------------- |
| SIRS 4 项阈值（体温 >38/<36 °C、心率 >90、呼吸 >20 或 PaCO₂ <32、WBC >12/<4 或杆状核 >10%）与「≥2 项」 | ACCP/SCCM 1992（Bone et al., *Chest* 101:1644-55）     |
| 糖尿病足感染 4 级（未感染 / 轻度 ≤2 cm / 中度 >2 cm 或更深 / 重度 = 局部感染 + SIRS）                    | IWGDF/IDSA 2023                                      |
| IWGDF 风险分层 0–3 的定义与筛查区间（12 / 6–12 / 3–6 / 1–3 个月）                               | IWGDF 2023 预防指南                                      |
| ABI < 0.9 = 下肢动脉病变                                                              | IWGDF PAD 指南                                         |
| 10 g Semmes-Weinstein 单丝测保护性感觉（LOPS）                                            | IWGDF 2023 预防指南（Rec 1-2 & Table 1）/ NICE NG19 §1.3.4 |
| HbA1c ≥ 58 mmol/mol（7.5%）= 血糖控制需强化                                              | NICE NG28 §1.6（本项目以 **≥64 mmol/mol / 8%** 为保守线）      |
| 糖尿病病程 > 10 年 → 神经病变 / PAD 风险升高                                                  | IWGDF-H01                                            |
| 伤口 > 14 天不愈合 = 慢性不愈合伤口                                                          | IWGDF-W02                                            |

### ⚠️ 我方设定（无直接指南来源，需说明是「产品化标定」）

| 项                                      | 说明                                          |
| -------------------------------------- | ------------------------------------------- |
| 类别百分比阈值 **30% / 40% / 50%**            | 用来把「连续分数」转成「是否命中某条规则」，属工程标定                 |
| 风险分档 **ratio ≥ 0.60 / 0.85**           | 同上                                          |
| 每个选项的**权重数值**（0–5 分）                   | 我方按临床重要性排序赋值                                |
| **弃权阈值 = 2 项不确定**                      | 我方**安全保守标定**；SIRS「≥2 项」仅为支持性证据，非推导来源        |
| 「高危足」`isVulnerable()` 含 **HbA1c > 8%** | 属 NICE NG19 / IWGDF 危险因素，**不在** IWGDF 风险分层内 |
| PC-04 的「升级」逻辑                          | 保守化设计：高危足 + 轻微发红即转诊                         |
| 把「类别得分 ≥30%」当作「LOPS 阳性」的**代理**         | LOPS 本是 10 g 单丝的**临床检查结果**，我们用问卷得分近似        |
| 既往溃疡 / 既往截肢 归入「紧急标志」红色提示块              | 二者是**风险标志**（IWGDF 3 级），非急症；共用红色提示块偏严但方向安全   |

> **已删除：** 原 `RISK_ACTION_MATRIX` 的时间窗（「2–4 周」「48 小时」「今天」）**已从代码中移除** —— 它与分诊引擎的时间窗重复且冲突，且为运营性建议而非指南原文。现在「该去哪、多急」只由 `triageEngine.ts` 一处决定。

## 9 · 评委提问速答

| 评委可能问           | 一句话回答                                                                                                     |
| --------------- | --------------------------------------------------------------------------------------------------------- |
| 「凭什么说该去急诊？」     | 任一红旗为「是」即急诊 —— 依据 IWGDF/IDSA 2023：重度足感染 = 局部感染 + SIRS，指南里**没有**「凑够几个症状」的数量门槛                              |
| 「为什么弃权阈值是 2？」   | 这是**我们主动的保守标定**，不是指南硬性规定：每多一项红旗「不确定」，就多一个未被排除的急症可能。SIRS「≥2 项」只是**支持**这个下限合理，不是它的推导来源；该值已参数化，可用合成数据再标定     |
| 「AI 会不会改结果？」    | 不会。层级由纯函数规则锁定（`locked: true`），LLM 拿到的系统提示明确禁止修改层级，另有 `isTierUnchanged()` 守卫                               |
| 「分数怎么算的？」       | 加权总分 ÷ 满分，分档 0.60 / 0.85。**权重是我方标定的**，只用于分档，不对外当严重度百分比                                                    |
| 「为什么三套分级？」      | 因为它们回答**不同问题**：就医层级答「去哪」、风险等级答「多严重」、IWGDF 答「多久复查一次」。故意解耦                                                  |
| 「IWGDF 分级在哪看？」  | 建议页的「IWGDF 风险等级」卡片，含等级定义、依据与建议筛查间隔                                                                        |
| 「18 条临床规则在哪看？」  | 建议页的「临床决策规则」卡片，只显示**本次评估真正命中的规则**，每条带来源徽标                                                                 |
| 「怎么保证公平？」       | 题库按年龄 / 病程 / 并发症 / HbA1c 个性化抽取，但**评估逻辑不按糖尿病类型、性别区分**；合成数据（Synthea）做公平性测试                                  |
| 「为什么不做 AI 看照片？」 | 明确不做。图片诊断属医疗器械范畴，且我们定位为**筛查与教育工具**。每个页面都有红框提示                                                             |
| 「用了哪 6 个数据源？」   | data.gov.sg（人群背景）、**NICE NG19**（分诊规则 / 转诊标准）、IWGDF（风险分层）、MIMIC-III（危重感染阈值校准）、Kaggle（高危画像）、Synthea（合成测试数据） |
