# 数据源登记 与 评估分级标准说明

**版本：** v3.10-consistency-fixes ｜ **日期：** 2026-10-13  
**用途：** 核对 6 个医学数据源的登记分类，并说明最终评估结果的判级标准与**复评间隔**（复评间隔算法与界面展示均已接入）。

> **配套文件：** 逐条「评估结果 ↔ 判定标准 ↔ 医学来源」对照（含诚实披露与 7 项不一致的修复记录）见 `docs/中文说明/assessment-criteria-source-mapping-zh.md`。

> **本版重要更正：** 此前实现中的两个阈值 —— 「≥3 个危险信号」和「≥4 个不确定」—— **是我方（AI）自行拟定的，并非来自任何医学数据库**。本版已按医学数据库**实际标准**修正。详见第二部分。

## 第二部分 · 评估结果的分级标准

> ⚠️ **应用里有三套并行分级**：风险等级（多严重）、就医层级（去哪）、IWGDF 分级（随访频率）。

### 2.1 医学依据（分级标准的真正来源）

**分级不是凭经验拟定的，而是来自两套权威定义：**

**① SIRS（全身炎症反应综合征）标准**  
来源：ACCP/SCCM 共识会议（Bone et al., *Chest* 1992;101:1644-55）  
**以下 4 项中满足 ≥2 项 = SIRS 阳性：**

| 项目  | 阈值                           |
| --- | ---------------------------- |
| 体温  | > 38 °C 或 < 36 °C            |
| 心率  | > 90 次/分                     |
| 呼吸  | > 20 次/分 或 PaCO₂ < 32 mmHg   |
| 白细胞 | > 12 或 < 4 ×10⁹/L，或杆状核 > 10% |

**② IWGDF/IDSA 糖尿病足感染分级**  
来源：IWGDF/IDSA 2023 指南

| 级别 | 名称     | 判据                      |
| -- | ------ | ----------------------- |
| 1  | 未感染    | 无局部/全身感染征象              |
| 2  | 轻度     | 仅皮肤/皮下；红斑 ≤ 2 cm        |
| 3  | 中度     | 深于皮肤/皮下，或红斑 > 2 cm      |
| 4  | **重度** | **局部感染 + SIRS（全身炎症反应）** |

> **关键结论：** 重度感染 = 局部感染 + SIRS，而 SIRS 需要 **≥2 项**征象。  
> 医学标准里**没有**"需要几个症状才算急症"的数量门槛 —— 任何单一严重征象（坏疽、扩散性感染、全身中毒表现）本身即为急症。

### 2.2 就医层级（Care Tier）—— 主结果

- **代码：** `triageEngine.ts` → `evaluateTriage(input)`
- 结果页顶部 TriageCard 显示的主结果（回答"现在该去哪就医"）
- 纯规则、确定性，按 `(priority, id)` 排序，**首个匹配即胜出**

| 优先级     | 规则       | 层级               | 触发条件（医学依据）                 |
| ------- | -------- | ---------------- | -------------------------- |
| **100** | RF-01    | **EMERGENCY**    | 发热 >38°C / 发冷（SIRS 体温项）    |
| **100** | RF-02    | **EMERGENCY**    | 红肿迅速蔓延（深部/扩散性感染）           |
| **100** | RF-03    | **EMERGENCY**    | 发黑 / 坏疽组织（组织坏死，威胁肢体）       |
| **100** | RF-04    | **EMERGENCY**    | 恶臭脓液（深部/坏死性感染）             |
| **100** | RF-05    | **EMERGENCY**    | 意识改变（脓毒症 / 器官功能障碍）         |
| **300** | PC-01…03 | **PRIMARY_CARE** | 浅表溃疡 / 新水泡 / 皮肤破损（无全身症状）   |
| **310** | PC-04    | **PRIMARY_CARE** | 高危足轻度发红（升级，escalated）      |
| **350** | AB-01    | **ABSTAIN**      | 回答自相矛盾                     |
| **350** | AB-02    | **ABSTAIN**      | **≥2 项红旗问题不明确**（无法排除 SIRS） |
| **400** | SC-01    | **SELF_CARE**    | 轻度受压发红、皮肤未破损               |
| **490** | SC-02    | **SELF_CARE**    | 无急性问题（默认兜底）                |

**注意：EMERGENCY 没有数量门槛** —— 上面 5 条 RF 规则各自独立，任一为"是"即触发急症。

### 2.3 弃权（ABSTAIN）阈值 —— 为什么是 2，不是 4

**医学依据：** 重度感染 = 局部感染 + SIRS，SIRS 需 **≥2 项**征象。

因此：**当 ≥2 项红旗问题"不明确"时，无法排除 SIRS → 无法排除重度感染 → 弃权（建议就医）。**

- 阈值 **2** 直接来自 SIRS 的"≥2 项"规则，不是拍脑袋定的。
- 之前的"**≥4**"没有任何医学依据，已删除。
- 若只有 1 项不明确，其余明确为"否"，则可排除 SIRS，继续正常分级。

### 2.4 风险等级（Risk Level）：`low` / `moderate` / `high` / `urgent`

- **代码：** `assessment.ts` → `calculateRiskWithProfile(answers, profile)`
- **依据：** 加权总分占比 `ratio = 总分 / 满分`

| 顺序 | 条件                           | 结果           |
| -- | ---------------------------- | ------------ |
| 1  | 紧急标志含 `chronicWound`         | **urgent**   |
| 2  | 有任何紧急标志，**或** `ratio ≥ 0.85` | **high**     |
| 3  | `ratio ≥ 0.60`               | **moderate** |
| 4  | 其余                           | **low**      |

### 2.5 IWGDF 分级（Category 0–3）

- **代码：** `clinicalRules.ts` → `mapToIWGDFCategory(result)`
- 用途：决定筛查频率（Category 0 每 12 个月 → Category 3 每 1–3 个月）；已在**建议页**展示

| 顺序 | 条件                                                     | 结果             | IWGDF 2023 定义                          |
| -- | ------------------------------------------------------ | -------------- | -------------------------------------- |
| 1  | 紧急标志含 `historyUlcer` / `amputationHistory` / `chronicWound` | **Category 3** | （LOPS 或 PAD）+ 既往溃疡/截肢/肾脏替代/Charcot 足 |
| 2  | LOPS / PAD / 足畸形 三项中 **≥2 项**                          | **Category 2** | LOPS+PAD，或 LOPS+足畸形，或 PAD+足畸形          |
| 3  | LOPS ≥30% **或** 循环（PAD）≥30%，且恰好一项                      | **Category 1** | LOPS **或** PAD                          |
| 4  | 其余                                                     | **Category 0** | 无 LOPS、无 PAD、无畸形                       |

> **v3.10 修复：** 此前规则要求「神经病变 ≥30%」才进入 1/2 级，导致**单纯 PAD 被判为 0 级**，与 IWGDF「LOPS **或** PAD 即 1 级」不符。现改为忠实组合规则；单独足畸形仍为 0 级（IWGDF 未把单独畸形列为风险类别）。

### 2.6 三套分级的关系

| 分级           | 回答的问题      | 展示位置                         |
| ------------ | ---------- | ---------------------------- |
| **就医层级**     | 现在该去**哪**？ | 结果页第 1 块（TriageCard，**主结果**） |
| **风险等级**     | 风险有多**大**？ | 结果页第 2 块                     |
| **IWGDF 分级** | 随访**频率**？  | **建议页「IWGDF 风险等级」卡片**（v3.10 起） |

**三者故意解耦。LLM 只能解释层级，不能修改层级。**

### 2.7 复评间隔 —— 为什么不是固定 3 个月

**代码：** `clinicalRules.ts` → `IWGDF_SCREENING_INTERVAL_MONTHS` / `screeningIntervalMonths()` / `nextScreeningDate()`；单测 `scripts/screening-interval-test.ts`（`npm run test:interval`，38 项）。

复评间隔由 **IWGDF 风险分级**决定，**不按年龄、也不是固定天数**：

| IWGDF 分级 | 含义                     | 本项目间隔     | 指南区间（IWGDF 2023） |
| -------- | ---------------------- | --------- | ---------------- |
| **0**    | 无 LOPS、无 PAD           | **12 个月** | 12 个月            |
| **1**    | LOPS **或** PAD          | **6 个月**  | 6–12 个月          |
| **2**    | LOPS / PAD / 足畸形 三者占其二 | **3 个月**  | 3–6 个月           |
| **3**    | 既往溃疡 / 截肢 / 终末期肾病      | **1 个月**  | 1–3 个月           |

- 每个区间取**更保守的一端**（1 级取 6 而非 12；2 级取 3 而非 6；3 级取 1 而非 3），保证不会比指南允许的**更稀疏**。
- **当前有开放伤口（`activeWound` / `chronicWound`）时不显示日期**，改为提示「请立即就医」—— 开放伤口不属于常规复评，由分诊引擎（TriageCard）给出就医层级。
- 日期按**自然月**推算（`setMonth`），不是固定 90 天；并按界面语言本地化（中文显示 `2027年1月8日`，不再显示 `Jan 8, 2027`）。
- 尚无评估记录时无法分层，回退到 **0 级（年度筛查）**。
- **「每日足部自查」是另一件事**（追踪页「每日足部打卡」，天天做），与专业复评频率无关。

> **界面状态（v3.10 起）：** 建议页展示 IWGDF 风险等级 + 建议筛查间隔；首页/追踪页的「下次评估」卡片在 v3.7 已移除（算法与单测保留）。`mapToIWGDFCategory()` 现由建议页直接调用。

> **更正记录：** ① 此前首页用的是**写死的 90 天**（`latest ? 90 : 30`），v3.6 起改为按 IWGDF 分级计算，v3.7 起该卡片从界面移除（算法保留）。② `IWGDF_CATEGORIES[].screeningFrequency` 的文字区间曾与数值表冲突（1 级 3–6 个月 / 2 级 1–3 个月 / 3 级 1–4 周），**v3.10 已统一**为 12 / 6–12 / 3–6 / 1–3 个月，并新增单测断言「数值必须落在文字区间内」。③ `RISK_ACTION_MATRIX` 因与分诊引擎时间窗重复且冲突，**v3.10 已删除**。

### 3.1 类别与题量

| 类别                  | 来源       | 题目 / 字段                                                       | 题数         |
| ------------------- | -------- | ------------------------------------------------------------- | ---------- |
| 红旗症状 `redflags`     | 问卷（必答）   | rf1–rf5                                                       | 5          |
| 神经病变 `neuropathy`   | 问卷       | n1–n10                                                        | 10         |
| 皮肤与指甲 `skin`        | 问卷       | sk1（必答）+ s1/s2/s6–s13                                         | 11         |
| 伤口 `wound`          | 问卷       | w1（必答）+ w2/w4/w5（条件追问）                                        | 4          |
| 血液循环 `circulation`  | 问卷       | c1–c8                                                         | 8          |
| **自我护理 `selfcare`** | **个人资料** | footInspection + barefootFrequency + footwearType             | **0（无题目）** |
| **病史 `history`**    | 问卷＋个人资料  | g1/g2/h1 + diabetesDuration + comorbidities + priorAmputation | 3          |

> 题库共 **41 题**。每次检查只问 **7 题安全必答 ＋ 4 题个性化**（＋ 条件追问）≈ 11 题，所以**满分随当次抽到的题浮动**，不再是一个固定值。  
> 逐题权重、选项分值、紧急标记、个性化规则见自动生成的 `docs/中文说明/question-bank-and-selection-logic-zh.md`（`npm run doc:bank`）。
